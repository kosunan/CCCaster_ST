# CCCaster Steam 1.5.1

カニファン版 **CCCaster_verB v1.5.1（3053324）** のネットコードを **MBAACC Steam 2017-01-05 / 32bit** へ移植したプロジェクトです。

共通の通信・入力・ロールバック・GUI・観戦・再戦・TrainingはvB 1.5.1を基準にし、ゲームアドレス、フック、保存領域、リプレイ構造はSteam版を解析して実装しています。実ロード先＋RVAで解決し、ASLRを維持します。カニファン版とのクロスプレイには対応しません。GUI左上の表示は`verSTEAM`です。

## 起動

- ゲームフォルダー内の`cccaster_st/CCCaster_Steam_GUI.exe`から起動します。
- ゲーム本体は含まれません。対応するSteam版を別途用意してください。

設定は各`cccaster_st`内の`cccaster_steam.ini`と機器別INIです。GUIのコントローラ設定で1P/2Pの機器・キー・パッドを割り当てられます。ゲーム内F4も使用できます。キャラ選択ではF1／STARTからD・背景アニメーション・HUDを設定できます。Dは色確定前の0〜8、対戦中は固定。背景とHUDは各端末の設定です。Rは通常7Fを基準に自動管理し、一時スパイクの予測上限は20Fです。

TrainingはFN1で保存・押下中停止、FN2で読込。通常Trainingの左／右＋FN2で、指定側の壁際へ相手、その内側へ自分を配置し、保存状態を保持します。DUMMY再生・録画中は従来の読込・録り直しを優先します。

1.5ではTrainingメニューの最上段に`CHARACTER`を追加。相手やステージの設定を保ちながらP1/P2のキャラ・ムーンを変更できます。隠し8体を含む39キャラを表示し、収録されたスタイルだけを選べます。キャラ変更後は以前のキャラの保存状態を破棄します。

起動時のファイル読込み・フォント構築、ゲーム内部の空き枠走査を最適化しました。RANDOM ONCEは直前のステージを除いて再抽選し、通常の再戦経路で読み込みます。対応する描画設定では完成画像をモニター周期で提示し、入力とゲーム更新は60Hzを維持します。Present後に画像が保持されない設定では元の描画経路を使います。

公開マッチングはSteam専用の暗号化一覧を使用します。終了時に残った募集の取消を回復し、新着順・経過時間・全角10文字までの名前を表示します。対戦者は同じ1.5.1を使用してください。

Training待受をONにすると、練習しながら対戦申込を受けられます。ゲーム内F5で承諾、F6で拒否。承諾時はTrainingを閉じて対戦を新規起動し、対戦終了後は同じ募集コードの待受へ戻ります。リプレイ観戦は標準リプレイ一覧へ直接起動します。

1.5.1ではSteamのゲーム内待機分岐を置き換え、演出・カメラ・停止状態の保存範囲も追加しました。

## ビルドと配置

`C:/msys64/mingw32`の32bitツールチェーンとCMakeを使用します。`build.bat`でReleaseビルドとC++テストを実行し、成果物を`build/bin/`へ出力します。CLI・GUI・DLLは同じビルドのものを組み合わせてください。

Git管理対象はvB 1.5.1と同じルート構成です。

```text
README.md  概要・ビルド・確認状況
VERSION    製品版番号
build.bat  32bit Releaseビルド・C++テスト
src/       CMake入口・assets・実装・tests・harness・開発用設定
```

開発環境の`docs/`・`test/`・`deploy.bat`・`deploy.ps1`などはローカル専用です。既存の対戦2窓＋観戦1窓バッチは`test/runtime/3窓起動.bat`に保持しています。これらはGitHubからの取得物に含まれません。

## 確認状況

1.5.1の32bit Release・C++65件・Python184件が成功。対戦2窓＋観戦1窓、キャラ選択設定、RANDOM再戦、Training待受、GUIコントローラ設定22項目を確認しました。片道65〜85ms・損失5%の同期試験は1,105確定Fで入力・代表状態の差分／欠落0です。

Cシオンの状態検査は3,056状態・16,556回の保存復元／再計算比較が一致し、独立監視領域も差分0。隠し・専用ムーン10組では限定12状態・74Fも一致。リプレイ一覧への直接起動と再生開始を確認しましたが、既存リプレイの再生終了は未確認です。ゲームEXEと元の設定を保持して実施しました。

検証は同一PCの独立コピーとローカル通知サーバーです。全キャラ・全技・全履歴の組合せ、相殺判定の実ヒット、別PC・実回線・長時間運用、物理パッド各種、全フレームの定刻完了は未網羅です。以前の1.5.0ではTrainingのキャラ変更、隠し8体とEclipse等13切替、対応する描画設定での200Hz提示要求と60Hzゲーム更新を確認しています。
