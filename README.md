# CCCaster Steam 1.5.8

カニファン版 **CCCaster_verB v1.5.8（1bb3f19）** のネットコードを **MBAACC Steam 2017-01-05 / 32bit** へ移植したプロジェクトです。

共通の通信・入力・ロールバック・GUI・観戦・再戦・TrainingはvB 1.5.8を基準にし、ゲームアドレス、フック、保存領域、リプレイ構造はSteam版を解析して実装しています。実ロード先＋RVAで解決し、ASLRを維持します。カニファン版とのクロスプレイには対応しません。GUI左上の表示は`verSTEAM`です。

## 起動

- ゲームフォルダー内の`cccaster_st/CCCaster_Steam_GUI.exe`から起動します。
- ゲーム本体は含まれません。対応するSteam版を別途用意してください。

設定は各`cccaster_st`内の`cccaster_steam.ini`と機器別INIです。GUIのコントローラ設定で1P/2Pの機器・キー・パッドを割り当てられます。ゲーム内F4も使用できます。キャラ選択ではF1／STARTからD・背景アニメーション・HUD・描画解像度・全画面・キャラフィルター・画面フィルター・縦横比・標準FPS表示を設定できます。Dは色確定前の0〜8、対戦中は固定。背景とHUDは各端末の設定です。Rは通常7Fを基準に自動管理し、一時スパイクの予測上限は20Fです。

TrainingはFN1で保存・押下中停止、FN2で読込。通常Trainingの左／右＋FN2で、指定側の壁際へ相手、その内側へ自分を配置し、保存状態を保持します。DUMMY再生・録画中は従来の読込・録り直しを優先します。

1.5ではTrainingメニューの最上段に`CHARACTER`を追加。相手やステージの設定を保ちながらP1/P2のキャラ・ムーンを変更できます。隠し8体を含む39キャラを表示し、収録されたスタイルだけを選べます。キャラ変更後は以前のキャラの保存状態を破棄します。

起動時のファイル読込み・フォント構築、ゲーム内部の空き枠走査を最適化しました。RANDOM ONCEは直前のステージを除いて再抽選し、通常の再戦経路で読み込みます。対応する描画設定では完成画像をモニター周期で提示し、入力とゲーム更新は60Hzを維持します。Present後に画像が保持されない設定では元の描画経路を使います。

公開マッチングはSteam専用の暗号化一覧を使用します。終了時に残った募集の取消を回復し、新着順・経過時間・全角10文字までの名前を表示します。対戦者は同じ1.5.8を使用してください。

Training待受をONにすると、練習しながら対戦申込を受けられます。ゲーム内F5で承諾、F6で拒否。承諾時はTrainingを閉じて対戦を新規起動し、対戦終了後は同じ募集コードの待受へ戻ります。リプレイ観戦は標準リプレイ一覧へ直接起動します。

1.5.4で追加したローカルの2人対戦にも対応。GUIのオフライン対戦、またはCLIの`--offline`で起動し、D0から設定できます。通常のポーズ、試合勝数、再戦、キャラ選択への復帰に対応します。

フレーム待機・入力採取・描画前の訂正処理をvB 1.5.8へ更新しました。ゲーム内FPSの集計からロールバック再計算を除きます。通常Training／オフライン対戦では自入力を過去へ差し替える実験機能を無効にし、待機後の入力を通常更新へ渡します。入力の先行表示も既定では無効です。

## ビルドと配置

`C:/msys64/mingw32`の32bitツールチェーンとCMakeを使用します。`build.bat`でReleaseビルドとC++テストを実行し、成果物を`build/bin/`へ出力します。CLI・GUI・DLLは同じビルドのものを組み合わせてください。

Git管理対象はvB 1.5.8と同じルート構成です。

```text
README.md  概要・ビルド・確認状況
VERSION    製品版番号
build.bat  32bit Releaseビルド・C++テスト
src/       CMake入口・assets・実装・tests・harness・開発用設定
```

開発環境の`docs/`・`test/`・`deploy.bat`・`deploy.ps1`などはローカル専用です。既存の対戦2窓＋観戦1窓バッチは`test/runtime/3窓起動.bat`に保持しています。これらはGitHubからの取得物に含まれません。未使用の直接入力書込みヘッダーと、カニファン専用の新規測定DLL／起動スクリプトは除外しています。

## 1.5.8の追加機能

- Trainingの`COLOR PALETTE`でカラー編集、プレビュー、ACT取込み、キャラ別EXTRA 1〜6の保存・選択。
- 対戦相手とのEXTRAカラー共有と受信表示設定。
- Trainingの`HITBOX`で当たり判定を表示。フレームバーの分類と標準Informationの説明も更新。
- ボスキャラ選択の許可設定。オンライン対戦では両者の許可を確認。
- キャラ選択で変更した背景・HUD・解像度・全画面・フィルター・縦横比・FPS表示を`display.ini`へ保存。Dは保存対象外。
- 対戦中のEsc・閉じる操作の抑止、GUI配置、起動時の資源準備をvB 1.5.8へ更新。

## 確認状況

build6はC++79/79成功、標準3環境へ配置済みです。Training／オフラインの終了操作を既存のプロセス終了へ接続し、終了理由の保存と対戦中の抑止を保持しました。実ゲームでローカル終了5ケース、対戦中の6種類の終了操作の抑止、相手への終了通知が成功。最終対戦1,080F／観戦1,078Fで確定入力・代表状態の差分／欠落0を確認しました。

build4の32bit Releaseビルド、C++79/79・Python251/251が成功。実Steam版でボス8体の選択、表示設定の保存・再起動、Trainingキャラ変更、HITBOX、EXTRAカラー選択・転送、日英GUIを確認しました。対戦／観戦はボス許可時1,082F、RANDOM再戦時1,730F／1,729F、EXTRA双方受信時1,052F／1,051Fで確定入力・代表状態の差分／欠落0です。

オフラインでは標準FPS60を維持し、入力から最終描画の903標本が成功。200Hzモニターの対応描画設定で、15.063秒間の提示要求199.364Hzとゲーム更新59.949Hzを観測しました。これはソフト側の提示要求で、物理的な画面走査や毎瞬間の上限を保証するものではありません。

検証は同一PC・仮想パッド・短時間です。パレットの手描き編集・ACTダイアログ全操作、全キャラ／全技、実回線の長時間試験は未網羅。機能試験とPython251件は終了修正前build4の結果で、終了harness改修後やbuild6での再実行済みとは扱いません。以前の1.5.4の結果は本版の確認済みに含めません。

ローカルのEsc／閉じる操作では、ゲーム本体が標準終了時だけ保存するINI・窓位置は保存されません。CCCasterの`display.ini`は設定操作時に保存します。
