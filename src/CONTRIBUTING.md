# 変更を加えるとき

開発ルールは [AGENTS.md](../AGENTS.md)、実行手順は [開発手順](../docs/DEVELOPMENT.md) に集約しています。変更前に [現行仕様](../docs/CURRENT_STATE.md) と [未解決事項](../docs/OPEN_ISSUES.md) を確認し、現在のコードと照合してください。

変更に対応する `docs/changelogs/CHANGELOG_YYYY-MM.md` に、日本語で判断理由・確認結果・残件を記録します。測定値・ログ・詳細設計は関連する設計記録へ置き、changelog にはその入口を示します。コミットする場合は先頭の変更見出しと日本語コミットメッセージを合わせます。

同期処理に関係がありそうな変更時、およびGitコミット直前には `cccaster-verify` に従って実ゲームテストを行います。コミット直前は文書・スキルだけの変更も対象とし、過去の成功結果だけでは省略しません。最終試験の成功を確認してからコミットし、その後に製品コード・ビルド入力・試験条件を変えた場合は再試験します。結果の記録だけの追記は再試験不要です。

既存の未コミット変更、ゲーム本体、設定、リプレイ、検証ログを保全してください。実装済みと実機確認済みを区別し、変更に必要な範囲の試験を行います。
