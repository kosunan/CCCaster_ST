# Steamオフライン実機確認

2026-09-11。CCCASTER_STEAM_TRAINING_PROBE=ON の隔離ビルドを、プロジェクト内の独立したSteamゲームコピーで使用。通常ビルドでは起動を拒否する。ネット対戦は検証ビルドでも拒否する。

1回目: `build_logs/steam_training_20260911_124305`、PID31308。ASLR base0x9F0000/entry0xB20982で版・再配置コード照合、DLL設置、入力2箇所置換、時計IAT・D3D捕捉成功。キャラ選択到達後、オフラインのMetronomeが開始されず高速進行していることを実メモリと画面で確認。

修正: SceneRunnerのオフライン経路で最初の通常フレームから既存Metronomeを開始し、絶対締切で待つ。毎回処理後16.667msを追加する方式ではない。解析用ScriptedInputをオフラインでもGameMemへ渡し、F4入力遮断のLocalInputGateを経由する。

2回目: `build_logs/steam_training_20260911_124452`、PID30316、base0x9F0000。正規Training分岐→キャラ選択→ロード→戦闘mode1まで到達。WASAPI activeログ。21標本の読取りで5.00038秒/WorldTimer300増、P2体力11400/10800、画面で戦闘と60FPS表示を確認した。平均の進行確認であり、瞬間更新精度を証明しない。HUDのネット用STEP/GAME表示はオフライン用実測がないので性能評価に使わない。

両回ともこの検証で起動したプロセスだけ終了。元Steamインストール、カニファン版のゲーム・設定・起動中プロセスは変更しない。

未確認: 手操作入力、F4の実機遮断、背景の2窓進行、再戦、SFXの聴感・ロールバック抑止、保存復元、ネット同期。通常起動ゲートを解除する根拠にはしない。
