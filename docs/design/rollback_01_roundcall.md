## 確認方法と境界

既存 `build_logs/steam_analysis/legacy.asm` と `steam.asm` を読取り、x87 と SSE のレジスター順ではなく分岐・式・利用側を比較した。実EXEの定数も pefile/struct で読取り、旧53D650(double)=60.0とSteam58D258(float)=60.0、旧53D9F8(double)=128.0とSteam58D2AC(float)=128.0、旧53D9C0(double)=256.0とSteam58D314(float)=256.0、旧53D978(double)/53D9C8(float)=480.0とSteam58D370(float)=480.0を確認した。

新規14断片の証拠命令は既存逆アセンブルの命令境界へ一致し、命令が各Steam保存先を直接参照することを機械検査した。既存断片を加えた node 3040〜3047 の旧96バイトを過不足なく網羅すること、保存先が重複しないことも検査した。

今回の担当範囲の未解決はない。これだけで保存表全体・2窓同期を実機確認した扱いにはしない。ゲーム起動・停止・プロセスメモリ書込み・共通ビルドは実施していない。共通表への統合と保存復元試験は親担当が行う。
