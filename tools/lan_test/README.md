# ローカルネットワーク自動テストシステム 使い方

1台の開発機（PC-A）と、LAN内の別PC（VM/PC-B）を用いて、ゲーム本体のネットワーク同期を完全自動テストするシステムです。
**VM側に `Agent` を常駐させておくことで、PC-Aからボタン1つで「プロセス停止→DLL転送→ゲーム再起動→対戦開始」が完結します。**

## ファイル構成
- `config.json`: IPアドレスやフォルダのパス設定
- `StartAgent.bat` / `agent.ps1` **(VM用)**: VM側で常にHTTP(8081)でポスティングを待つ常駐アプリ
- `RunAll.bat` / `controller.ps1` **(PC-A用)**: VM側Agentに命令を送り、デプロイと両PCの起動を一気に行う司令塔

*(※ `.bat` は実行権限エラーを回避するラッパーです。常に `.bat` 側をダブルクリックしてください)*

## 動作手順

### 1. VM (PC-B) での準備 (最初の1回だけ)
1. VM側のゲームフォルダ(`MBAA.exe`がある場所の `cccaster`フォルダ内)に以下のファイルをコピーします。
   - `StartAgent.bat`
   - `agent.ps1`
2. VM上で `StartAgent.bat` をダブルクリックして実行します。
   - `Listening on port 8081...` と黒い画面が出たままになれば準備完了です。この画面はずっと開きっぱなしにします。

### 2. ホスト (PC-A) での準備
1. `config.json` を自分の環境に合わせて修正します。
   - `host_pc.ip`: VMから見て繋ぎにこれるホストPCのIP (省略・`127.0.0.1`だと自動推測します)
   - `client_pc.ip`: VMのIPアドレス (`agent.ps1` が動いているIP)

### 3. テスト実行 (いつもの操作)
1. **PC-Aのエクスプローラから `RunAll.bat` をダブルクリックします。**
2. 以下の処理が全自動で行われます。
   1. VM内の過去のゲームプロセスを強制終了
   2. PC-Aの過去のゲームプロセスを強制終了
   3. PC-Aのビルドフォルダから `CCCaster_v10.exe` と `libcccaster_hook.dll` をHTTPSでVMのAgentへ送信（上書き保存）
   4. VM側でクライアントとしてゲーム起動を指示
   5. PC-A側でホストとしてゲーム起動

これだけで、最新のDLLを使って両画面で自動キャラクター選択・ランダム入力対戦が開始されます！
テストをやり直す時は、ゲーム画面を閉じる必要すらありません。単に `RunAll.bat` をもう一度ダブルクリックするだけで、全プロセスが強制終了されて最新状態で再スタートします。
